# SmartNest: 3-minute demo script

`node e2e/record-demo.mjs` (in `frontend`) records the captioned, silent video `docs/demo/smartnest-demo.webm`
(about 2:45). The lines below are the narration to read over it, in the same order.

| Time | On screen | Say |
|---|---|---|
| 0:00 | Empty app, status badges | "SmartNest plans a whole home inside your budget. The badges show it is using real Google Shopping data." |
| 0:12 | Demo message typed and sent | "I tell it: 2BHK, ₹2 lakh, minimalist. Four specialist agents now work on it." |
| 0:30 | Plan appears, scroll rooms | "Ten items across four rooms. Every price and link is a real listing, and the total is inside the budget." |
| 0:55 | Badges, Why this? | "Stock is only marked confirmed when the listing says so; everything else is unverified. Why this? shows the score and what the listing did not state." |
| 1:10 | Alternatives, Use this | "I can swap in an alternative. SmartNest re-checks the budget and refuses anything that would break it." |
| 1:30 | Shortlist, Compare | "I shortlist two products and compare them side by side." |
| 1:45 | Add to cart, Cart tab | "I add products to my cart, or all of SmartNest's picks at once. The cart keeps a running total, never goes over the budget, and each link opens the seller; SmartNest sells nothing." |
| 2:00 | Budget tab | "The budget dashboard shows spend by room and category, and allocated versus spent. Each item has a hard ceiling." |
| 2:15 | Chat: remove TV unit, fridge out of stock, budget cut | "I change my mind in chat. The Coordinator re-plans only what is affected: a missing item, an out-of-stock fridge, a smaller budget. If something cannot fit, it says so instead of bending a rule." |
| 2:40 | Agents tab | "Every message between agents is Ed25519-signed and verified before an agent acts. The timeline shows each decision and each replan." |
| 2:50 | Closing caption | "Real data, hard budget limits, honest uncertainty, signed agent messages." |
